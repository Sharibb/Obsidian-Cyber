# Study Timeline and General Resources

## Suggested 8-Week Timeline

| Week | Focus |
|---|---|
| 1 | Scoping/OSINT refresher, report template build, schedule proctored slot |
| 2-3 | Binary exploitation fundamentals (BOF, mona.py, ROP basics) |
| 4 | IoT/firmware analysis |
| 5 | Web/API/JWT deep dive |
| 6 | AD + pivoting full-chain mock runs (reinforcement, timed) |
| 7 | Cloud misconfig review, integration mock combining 2+ domains |
| 8 | Full 24hr (or 2x12hr) mock on practice range, mock report writeup, logistics check |

## General Resources

- EC-Council iLabs / practice range (90-day bundled access with exam voucher)
- HTB: BOF Prep, IoT-tagged machines, Pro Labs for multi-segment chains
- PortSwigger Web Security Academy: JWT + API sections
- Ghidra + pwndbg/gdb-peda documentation
- binwalk / firmware-mod-kit docs for IoT
- flAWS / flAWS2 for cloud misconfig practice

## Exam-Day Notes

- Front-load easy wins across all segments before deep-diving one target
- Timebox: if stuck 60-90min past estimate, pivot and return later
- Screenshot every objective as you achieve it, do not rely on end-of-exam memory
- 2x12hr split recommended if 24hr straight is a stamina concern, gives a reset window
- Begin report drafting same day exam ends, while context is fresh
